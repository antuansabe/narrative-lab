# Narrative Lab

Corpus-level narrative analysis platform (Ashoka / Hello World / Hola América pilot).
Extracted from CAS (`scoring-matrix-demo`) as a standalone product, July 2026.

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in keys
npm run dev                  # http://localhost:3000
```

Health check: `http://localhost:3000/api/health`

## Read first

1. `CLAUDE.md` — session rules, non-negotiables, visual system
2. `NARRATIVE_LAB_BUILD_PLAN.md` — phased plan, status tracker, open decisions
